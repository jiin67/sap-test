## 참고
1. **동시 작업 간섭**: 같은 SAP GUI에서 다른 테스트(ZSD600)가 동시에 돌았고, 그쪽 세션 정리 스크립트(`cleanup_popups.vbs`)가 제 테스트 세션을 두 번 닫았습니다.
   - 058S 본사확정취소: 로그가 도중에 끊김. 재조회(LED 빨강)와 FEEH1 0건으로 반영을 확인함.
   - 100273 회귀: 세션 생성 실패로 1회 중단. 미확정 상태라 오류 메시지만 나오고 DB 변경은 없었음. 재수행 결과 PASS.
   - SUBS_TYPE 원복: 2건이 저장 전에 중단되어, 재수행 후 저장함.
   - 최종 상태는 모두 테이블 조회로 확인했습니다.
2. **0101 신규 컬럼**: 058A·058S 0101에 `SUBSWRTMONTH`, `WRTDATE` 컬럼이 새로 보입니다(09-13에는 없음). 시나리오 범위 밖이라 참고로만 기록합니다.
3. **0101 캡처 한계**: 기술료/출장비/통화 열이 화면 오른쪽 밖에 있어 캡처에는 보이지 않습니다. S-03 판정은 ALV 셀 값(로그 `S17_D14_N6_S_058S_SVCNEW`) 기준입니다.
4. **FEEH1 기존 데이터**: 키가 바뀌어 기존 FEEH1 행은 SUBS_TYPE 공백(일반)으로 읽힙니다. 운영 이관 시 이미 처리된 구독분이 있다면 보정이 필요한지 확인을 권장합니다.
