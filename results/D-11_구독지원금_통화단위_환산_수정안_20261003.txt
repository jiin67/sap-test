[원인]  형(type) 이 다른 필드끼리 그대로 더했다.
 - ZCRM_CICCOST_M-MAXTECHPRICE / TRIPPRICE : CURR 13,2  참조통화 WAERS
     KRW 는 소수점 0자리 통화라 SAP 내부값은 1/100 로 저장된다. 10,000원 = 내부 100.00, 20,000원 = 200.00
     화면·SE16N 은 통화 환산(×100)해서 10,000 / 20,000 으로 보여 준다.
     (058F01 1421~1424 set_currency_column('WAERS'), 060F01 879/886 CFIELDNAME 'WAERS')
 - gt_data_total-assptfee (058F01 TOP 22행), gt_data1-assptfee (060 TOP 69행) : TYPE i  (원 단위 정수)
     기존 건수×단가 계산도 정수 원 단위(5,000) 이고, 전표는 058F01 554 WRITE ... TO lv_wrbtr 로 그 값을 그대로 쓴다.
 - 따라서  assptfee = maxtechprice + tripprice  →  100.00 + 200.00 = 300  (원 단위 30,000 이 아니라 300)
   해당 줄: ZCRMR058_1F01 1618,  ZCRMR060_1F01 1543·1556

[수정안]  통화 내부값 → 외부값(원 단위) 으로 환산해서 정수 필드에 넣는다. 공용 FORM 1개를 ZCRMR060_1F01 에 두고

(1) ZCRMR060_1F01  맨 끝에 FORM 추가
----------------------------------------------------------------------
*&---------------------------------------------------------------------*
*&      Form  ZF_SUBS_FEE_TO_INT
*&---------------------------------------------------------------------*
*  SR03000035400 D-11 : 구독 지원금(원 단위 정수) = 기술료 + 출장비
*  MAXTECHPRICE/TRIPPRICE 는 CURR(참조 WAERS) 라 KRW 내부값이 1/100
*  (10,000원 = 100.00). ASSPTFEE 는 TYPE i 라 통화 외부값으로 환산해 넣는다.
*----------------------------------------------------------------------*
FORM zf_subs_fee_to_int USING    pv_tech  TYPE zcrm_ciccost_m-maxtechprice
                                 pv_trip  TYPE zcrm_ciccost_m-tripprice
                                 pv_waers TYPE waers
                        CHANGING pv_fee   TYPE i.

  DATA : lv_waers TYPE waers,
         lv_int   TYPE bapicurr-bapicurr,
         lv_ext   TYPE bapicurr-bapicurr.

  lv_waers = pv_waers.
  IF lv_waers IS INITIAL.
    lv_waers = 'KRW'.
  ENDIF.

  lv_int = pv_tech + pv_trip.

  CALL FUNCTION 'BAPI_CURRENCY_CONV_TO_EXTERNAL'
    EXPORTING
      currency        = lv_waers
      amount_internal = lv_int
    IMPORTING
      amount_external = lv_ext.

  pv_fee = lv_ext.

ENDFORM.                    " ZF_SUBS_FEE_TO_INT
----------------------------------------------------------------------

  gt_data_total-assptfee = gt_data_total-maxtechprice + gt_data_total-tripprice.
