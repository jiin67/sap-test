결정 1) 구독 무상지원금의 기술료·출장비는 '구독 N년이후' 상담건만 청구한다. (D-16)

   ※ 240074 = 나비엔 구독사업팀(공통). '24007' 로 적어 주셨는데 코스트센터는 6자리 240074 로 보고 작성함.

D-16. 기술료·출장비 합산을 'N년이후' 상담으로 제한  →  ABAP 수정 (2곳 + 확인 1곳)
------------------------------------------------------------------------------------
[판정 기준]
 다른 프로그램과 같은 기준을 쓴다: ZCRM_CICSVC_NEW-SUBSWRTMONTH > 0 이면 'N년이후', 0 이하이면 'N년이내'.
 (ZCRMR052 소비자가 ZPA2 분기, ZCRMR177_1 '구독무상(N년이후/이내)' 문구가 이 기준)

[사전 확인] ZCRMR060_1T01 의 gt_base 정의에 SUBSWRTMONTH 필드가 있는지 확인.
 GET_BASE(ZCRMR060_1F01 75~104)가 SELECT * ... INTO CORRESPONDING FIELDS OF TABLE gt_base FROM zcrm_cicsvc_new 이므로
 gt_base 에 같은 이름의 필드만 있으면 자동으로 채워진다. 없으면 gt_base 구조에
     subswrtmonth TYPE zcrm_cicsvc_new-subswrtmonth,
 한 줄을 추가한다(INCLUDE STRUCTURE zcrm_cicsvc_new 로 선언돼 있으면 이미 있음).

(3) 확인만: ZCRMR058_1F01 FORM zf_map_cost_0101 (현재 1649~1676, 지급대상데이터조회 화면 101)
  상담별 기술료·출장비를 ZCRM_CICCOST_M 에서 그대로 보여 준다. N년이내 상담에 CIC 금액이 있으면 목록에는 보이지만
  합산에는 안 들어가게 된다. 혼동을 막으려면 같은 조건(gs_cicsvc_ext-subswrtmonth <= 0 이면 금액 CLEAR)을 넣거나
  '청구 제외' 표시를 두는 것을 권장. 기능상 필수는 아님.

[동작 결과]
 - N년이후 상담만 합산되고, N년이내 상담만 있는 구독 대리점은 지원금 0 → 기존 0원 제외 로직(SET_MCOMP 356~363)으로 확정에서 빠진다.
 - 건수 행(060S line_idx 1)은 지금처럼 N년이내 상담도 세지만 금액에는 쓰지 않는다(표시용).
 - CIC 가 N년이내 상담에 금액을 0 으로 보내는 경우에도 결과는 같다(이중 안전장치).

D-17. 구독건 코스트센터 = 240074  →  설정 변경 (ABAP 변경 없음)
------------------------------------------------------------------------------------
[지금 상태 (2026-09-30 S01~S10 설정 이후)]
 ZCRM_KOSTL_T 의 구독 정산유형 행: 코스트센터(KOSTL) = 센터별(CT18 260014, CT19 260037 …), 예산센터(ZZKOSTL) = 240074.
 → 171S 전표 3100069966 : 5328210 / 코스트센터 260014 / 예산센터 240074
 → 058S 전표 3100069980 : 5328170 / 코스트센터 260037 / 예산센터 240074
 (2026-09-28 결정 당시의 Z11 설정은 코스트센터·예산센터 모두 240074 였음 - 09-30 재설정 때 코스트센터가 센터별로 바뀐 것)

[수정 내용] SM30 유지보수 뷰 ZCRM_KOSTL_V (AS정산 코스트센터 유지보수) 에서

[프로그램 변경이 필요 없는 이유]

 센터별 행의 값을 전부 240074 로 두면 어느 센터 대리점이든 구독 전표는 240074 로 간다.
