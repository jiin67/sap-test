## 미해결 발견 (개발자 확인 요청)
1. **ATP 점검 실패 원인**: PNGB3500035L001 은 MARA(FERT, EA) 및 **MARC 플랜트 6100(가용성점검그룹 02)·1100(Z2)** 에 모두 존재한다. 그런데 헤더 더블클릭 ATP 점검과 CREA_ORD 모두 "마스터 레코드가 없습니다 / ATP를 점검할 수 없습니다" 로 실패. 플랜트 미확장이 원인이 아니므로 **ATP 함수(ZCRMF02_RFC_MAT_AVAILABILITY)의 대상 시스템(RFC)·플랜트 결정 로직**을 확인 필요. 비교: 1422 주문 자재 20010472A 도 6100/02 로 동일 구성.
2. **R9-06 검증 시점**: 자재변경 대화상자는 Enter 시 MARA 만 검증(M23)하고 플랜트(MARC, M24)는 즉시 검증하지 않는 것으로 보임(PNGB 입력 시 즉시 통과). 시나리오 R9-06 은 "입력→Enter→플랜트 미등록 오류"를 기대하므로 설계 의도 확인 필요.
3. **R9-04 무음 처리**: 동일 자재 재입력 시 차단 메시지(M25) 없이 대화상자가 닫힘. 메시지 표시가 요구사항이면 보완 대상.
4. **DEL-04 선행 가드**: 판매오더 자체가 없는 주문에서 납품삭제→예 를 누르면 "판매오더가 생성되지 않았습니다" 로그가 남음(정상 가드). 판매오더는 있고 납품만 없는 경우에만 "삭제할 납품문서가 없습니다" 가 나옴.
